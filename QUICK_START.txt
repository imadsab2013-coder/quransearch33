1️⃣  quran_search_engine.py
   ✅ محرك البحث المستقل الكامل
   ✅ يعمل عبر سطر الأوامر (command line)
   ✅ لا يحتاج إلى Streamlit
   ✅ بحث تفاعلي سهل الاستخدام
   
   كيفية التشغيل:
   ➜ python quran_search_engine.py
   
   الميزات:

   • البحث عن الألفاظ
   • معالجة تلقائية للتشكيل
   • عرض السياق (6 آيات قبل و 6 بعد)
   • واجهة نصية سهلة

   ✅ تطبيق ويب كامل مع واجهة رسومية

   ✅ واجهة حديثة وسهلة الاستخدام
   ✅ يدعم كل الميزات بصيغة مرئية
   
   كيفية التشغيل:
   ➜ streamlit run app_streamlit.py
   
   الميزات:
   • بحث موازي (السياق واللفاظ في نفس الوقت)
   • واجهة رسومية جميلة
   • عرض النتائج بشكل مرتب
   • ضغط مزدوج على الآيات لعرض السياق

📋 البدء السريع (Quick Start)
════════════════════════════════════════════════════════════════════════════════

1. تثبيت المتطلبات:
   ➜ pip install -r requirements.txt

2. اختبار الإعدادات:
   ➜ python test_setup.py

3. اختر طريقة الاستخدام:

   ▬▬ الخيار A: واجهة سطر الأوامر (مستقلة)
   ➜ python quran_search_engine.py
   
   ▬▬ الخيار B: واجهة الويب (تفاعلية)
   ➜ streamlit run app_streamlit.py

⚙️  متطلبات البيانات
════════════════════════════════════════════════════════════════════════════════

📂 يجب أن يكون لديك مجلد data/ يحتوي على:

data/
├── data_quran.xlsx        (إجباري)
│   └── الأعمدة:
│       • السورة
│       • رقم الآية
│       • نص الآية (مع التشكيل)
│
└── data_words.xlsx        (اختياري لكن مهم)
    └── الأعمدة:
        • اللفظ
        • عدد الورود
        • السورة
        • رقم الآية
        • نص الآية الكاملة

⚠️  ملاحظة: يجب أن يكون النص مع التشكيل الكامل (الضمات والفتحات)
   مثال: الْحَمْدُ لِلَّهِ (وليس: الحمد لله)

🔍 الفرق بين البحثين
════════════════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────────────────┐
│ البحث بالسياق (Context Search)                                            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ ➤ البحث من: نص الآيات في data_quran.xlsx                                 │
│ ➤ الاستخدام: فهم معنى الآية في سياقها الكامل                             │
│ ➤ النتيجة: الآية + 6 آيات قبلها + 6 آيات بعدها (13 آية كاملة)           │
│                                                                             │
│ مثال:
│ ابحث عن: "اني جاعل في الارض خليفة"
│ النتيجة: البقرة:30 مع 12 آية حولها
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ البحث عن اللفظ (Word Search)                                               │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ ➤ البحث من: ملف الألفاظ data_words.xlsx                                   │
│ ➤ الاستخدام: معرفة جميع مواضع كلمة معينة في القرآن                      │
│ ➤ النتيجة: قائمة بجميع الآيات + عدد مرات الورود                           │
│                                                                             │
│ مثال:
│ ابحث عن: "الحمد"
│ النتيجة: 38 موضع + الآيات الكاملة
│ ثم اختر آية → اضغط السياق → رؤية 13 آية حول الآية المختارة
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

💡 نصائح مهمة
════════════════════════════════════════════════════════════════════════════════

✓ التشكيل لا يؤثر على البحث
  • ابحث عن: "الحمد" أو "الْحَمْد" أو "الْحَمْدُ" → نفس النتيجة

✓ يمكنك البحث عن جزء من الآية
  • بدلاً من: "وإذا قال ربك للملائكة إني جاعل في الأرض خليفة"
  • ابحث عن: "إني جاعل في الأرض" أو حتى "اني جاعل"

✓ البحث يغير تلقائياً:
  • ا ← إ, أ, آ (جميع الألفات متطابقة)
  • ي ← ى (اليائ والألف المقصورة)
  • ه ← ة (الهاء والتاء المربوطة)

✓ عند استخدام Streamlit، انسخ النتائج مباشرة
  • اضغط Ctrl+A ثم Ctrl+C

✓ للبحث المتقدم، استخدم command line
  • البرنامج يوضح جميع خيارات البحث
